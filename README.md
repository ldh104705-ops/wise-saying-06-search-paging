# 명언 앱 ⑥ 검색·페이징 (13~14단계)

레이어드 구조(Controller · Service · Repository) 명언 앱에 검색과 페이징을 붙인 버전입니다. 저장소는 메모리 리스트입니다.

## 명령어

| 명령 | 설명 |
| --- | --- |
| `등록` | 명언·작가 입력 후 등록 |
| `목록` | 최신순, 한 페이지 최대 5개, page 생략 시 1페이지 |
| `목록?page=2` | 2페이지 |
| `목록?keywordType=content&keyword=과거` | 명언 내용 부분 일치 검색 |
| `목록?keywordType=author&keyword=작자` | 작가 부분 일치 검색 |
| `목록?keywordType=author&keyword=작자&page=2` | 검색 결과 기준 페이징 |
| `삭제?id=N` / `수정?id=N` | 없는 번호면 `N번 명언은 존재하지 않습니다.` |
| `종료` | 프로그램 종료 |

- 앱 시작 시 명언이 0개면 샘플 명언 10개(`명언 1`~`명언 10`, `작자미상 1`~`작자미상 10`)를 만듭니다.
- 목록 아래에 `페이지 : [1] / 2` 처럼 현재 페이지를 `[ ]` 로 표시합니다.

```
명령) 목록?keywordType=content&keyword=과거
----------------------
검색타입 : content
검색어 : 과거
----------------------
번호 / 작가 / 명언
----------------------
2 / 작자미상 / 과거에 집착하지 마라.
----------------------
페이지 : [1]
```

## 구조

- `App` : 입력을 받아 컨트롤러로 전달
- `WiseSayingController` : 입출력, 검색 조건·페이지 메뉴 출력
- `WiseSayingService` : 샘플 생성, 페이지 크기(5) 등 비즈니스 로직
- `WiseSayingRepository` : 검색 필터 + 최신순 정렬 + 페이징(`Page`) 조회
- `AppContext` / `AppConfig` : 공유 객체 생성, 샘플 데이터 on/off (테스트에서는 off)

## 테스트

```
./gradlew test
```

- `WiseSayingControllerTest` : 종료·등록·목록·삭제·수정, 없는 번호 삭제·수정 (샘플 없이 시작)
- `WiseSayingSearchPagingTest` : 내용/작가 검색, 샘플 10개 1페이지(10~6번)·2페이지(5~1번), 내용에 `1` 검색 시 10번·1번, 검색+페이징
